# Demostraciones T19-T20 y Actividad 8

Esta carpeta reúne materiales prácticos para monitorización, observabilidad, alertas e incidentes del Módulo 3.

## Actividad 8 - Starter adaptable

- [Código base de monitorización y observabilidad](actividad8_observabilidad_starter/README.md)

El starter está pensado para proyectos heterogéneos: machine learning, deep learning, datos tabulares, texto, imágenes, señales y video.

No impone un único stack. La lógica común es:

```text
indicadores
→ SLO / umbrales
→ alertas
→ incidentes simulados
→ runbooks
→ respuesta
→ evidencia
```

Incluye una demostración tabular mínima, MLflow opcional, logs, trazas simplificadas, PSI para data drift, dashboard, simulador de incidentes y plantillas para adaptar la actividad al proyecto de cada equipo.
