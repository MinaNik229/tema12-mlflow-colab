# Demostraciones T15-T16 listas para clase

Este directorio contiene dos prácticas ejecutables para acompañar los Temas 15 y 16.

- `tema15_contenedorizacion_fraude/`: modelo -> `model.pkl` -> FastAPI -> Docker -> pruebas.
- `tema16_desercion_api_docker_nube/`: modelo de deserción -> API -> cliente -> Docker -> simulación PaaS -> documentación técnica.

Cada carpeta incluye un README con el orden exacto de ejecución y archivos ya preparados para que durante la clase solo sea necesario ejecutar y explicar.
